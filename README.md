# Que tal praticar?
Os conceitos de pra se trabalhar com vetores são desafiadores no início. É importante treinar bastante, mas não é algo de outro mundo. Sei que você é capaz de fazer o seguinte desafio com base no que aprendeu. Vamos fazer 3 exercícios.

## EXERCÍCIO 1

Preencha um vetor de n números com valores aleatórios advindos do console.

Ordene este vetor.

Em seguida, receba um nome e exiba na tela a quantidade de vogais que esse nome possui.

Dica: O Bubble Sort pode ser um grande aliado nesse exerício e o tipo char é bom pra trabalhar com um vetor de caracteres.

## EXERCÍCIO 2

Conseguiu? Que legal! Agora, exercite esse outro:

Receba um vetor de n números inteiros inseridos pelo usuário.

Percorra o vetor altere o valor de cada posição: se o valor da posição for par, seu novo valor deve ser multiplicado por 2, se for ímpar, o novo valor da posição deve ser ele mesmo elevado por 2.

Exiba o conteúdo do novo vetor.

Exemplo: [5, 11, 4, 2, 1]

Resultado: [25, 121, 8, 4, 1]

Dica: Lembre que % traz o resto da divisão, e não se esqueça da função Math.power(n).

## EXERCÍCIO 3

Deu certo? Vamos ver se você é fera: quero ver você ser o rei dos vetores :)

Receba um nome qualquer do usuário.

Percorra esse nome num vetor e exiba o vetor com o nome invertido.

Exemplo: "EBAC"

Resultado: "CABE"

Dica: Use as posições do vetor e guarde os valores momentâneos numa variável pra facilitar.
